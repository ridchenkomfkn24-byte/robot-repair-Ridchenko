* **Що не вийшло або забрало найбільше часу:**
  * Пошук причини, чому снаряд не з'являвся на сцені при натисканні **C**. Довелося поетапно перевіряти виклики точковими логами у Console (`Debug.LogError`/`Debug.LogWarning`), перевірити наявність компонента `Projectile` на префабі та застосувати зміни до сцени через **Apply Overrides**.

* **Що зрозумів про `Instantiate`, шари фізики та налагодження:**
  * Метод `Instantiate` створює динамічну копію (клон) префаба безпосередньо під час гри, після чого через `GetComponent` можна одразу викликати його внутрішні функції.
  * Матриця колізій (Layer Collision Matrix) у 2D Physics дозволяє повністю ігнорувати зіткнення між вибраними шарами, що вирішує проблему застрягання снаряда у колайдері самого гравця.
  * Покрокове використання `Debug.Log` у поєднанні з перевіркою появи об'єктів у Hierarchy під час Play Mode — найшвидший спосіб знайти, де саме розривається ланцюжок виклику функцій.

### 06.11.2026 — Юніт 5: HUD, діалоги, ігровий цикл

**Що зроблено:**
Створено HUD через UI Toolkit: портрет персонажа та смугу здоров’я, яка зменшується від ударів і збільшується після підбору аптечки. Додано NPC з підказкою клавіші X та реплікою на 4 секунди. Реалізовано плавні екрани перемоги й поразки та перезапуск сцени через 3 секунди. Перевірено обидва варіанти завершення гри.

**Що не вийшло або забрало найбільше часу:**
Найбільше часу зайняло налаштування розмірів і положення елементів у UI Builder. Спочатку підказка над NPC була завеликою, а панель діалогу займала забагато місця. Виправив масштаб підказки та відступи панелі. Також усунув помилку зі скриптом NonPlayerCharacter, призначив клавішу X і налаштував плавну появу екрана перемоги.

**Що зрозумів про UI Toolkit, синглтон і raycast:**
UI Toolkit дозволяє створювати інтерфейс як дерево елементів, до яких код звертається за іменами. UIHandler.instance дає іншим скриптам доступ до єдиного об’єкта керування HUD — це приклад використання синглтона. Raycast перевіряє, чи є NPC поблизу в напрямку погляду персонажа. Перетворення (float) потрібне, щоб отримати дробову частку здоров’я для ширини смуги.

**Що каже мій NPC і чому саме це:**
«Допоможи полагодити всіх роботів! Натискай C, щоб стріляти». Ця репліка пояснює гравцю мету гри та клавішу для ремонту роботів.

**Умови перемоги й поразки в моєму зрізі:**
Перемога настає після ремонту всіх ворогів, поразка — коли здоров’я персонажа досягає нуля. В обох випадках показується відповідний екран, а через 3 секунди рівень запускається заново. Прапорець gameOver запобігає повторному виклику завершення гри щокадру.
