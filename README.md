- Налаштовано `Tilemap Collider 2D` та `Composite Collider 2D` для водойми з вимкненням колайдерів на тайлах підлоги (`Collider Type = None`).

**Що не вийшло або забрало найбільше часу:**
- Найбільше часу пішло на правильне налаштування структури проєкту у зв'язці з GitHub Desktop та розбиття тайлсетів через Sprite Editor.

**Що зрозумів про FixedUpdate і колайдери:**
- Зрозумів, що рух об'єктів із фізичними компонентами потрібно робити у `FixedUpdate`, бо він працює із чітким фіксованим кроком часу.
- Використання `MovePosition` дає змогу фізичному рушію коректно обраховувати зіткнення замість телепортації об'єкта через `transform.position`.
- Для тайлмапів краще використовувати `Composite Collider 2D` з операцією `Merge`, щоб злити окремі квадрати плит у суцільний контур і прибрати чіпляння на стиках.

**Що в рівні вийшло не так, як у фізичному паспорті, і чому:**
- Перпочатковий розмір водойми довелося трохи змінити під час малювання, щоб гравець мав достатньо простору для маневрування між декораціями та зоною шкоди.

- Виконано додаткове завдання: створено варіант сильної аптечки (+2 HP) та розставлено смугу перешкод на рівні.

**Що не вийшло або забрало найбільше часу:**
- Розібратися із викликом методів тригерів (`OnTriggerEnter2D` vs `OnTriggerStay2D`) та виправлення помилки CS0122 через захист приватних змінних.

**Що зрозумів про тригери, public і private:**
- Колайдер з увімкненим `Is Trigger` пропускає об'єкти крізь себе та викликає події в коді замість фізичного зіткнення.
- Змінні `public` видно в Inspector та інших скриптах, а приватні поля захищають внутрішній стан класу від небажаних змін. Властивість `{ get; }` дозволяє безпечно читати значення змінної без права її зміни.

**Яке значення Time Invincible обрав і для якого гравця:**
- Обрав `Time Invincible = 2.0s`. Це підходить для казуальних гравців, бо дає достатньо часу вибігти із зони шкоди та зреагувати на небезпеку.
